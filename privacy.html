Privacy Policy

यह Privacy Policy बताती है कि Indian Vivah Matrimony user information को किस प्रकार collect, use, display और protect करने का प्रयास करता है।

1. हम कौन-सी जानकारी collect कर सकते हैं

Registration, profile creation और matrimonial service के दौरान user से निम्न प्रकार की information ली जा सकती है:

  • Name
  • Mobile number
  • Email address
  • Date of birth / age
  • Gender
  • Religion / community related profile information
  • Marital status
  • Education
  • Occupation / work details
  • Income-related profile information
  • State, district, city और address-related information
  • Height, diet और lifestyle-related profile information
  • Profile photographs
  • Membership और payment verification details

2. Information का उपयोग

Collected information का उपयोग मुख्य रूप से निम्न उद्देश्यों के लिए किया जा सकता है:

  • User profile create और maintain करने के लिए
  • Matrimonial profiles display और discover कराने के लिए
  • Potential matches या matrimonial assistance के लिए
  • Membership features provide करने के लिए
  • Account और service-related communication के लिए
  • Payment verification के लिए
  • Fraud, misuse और security issues detect करने के लिए
  • Website और app functionality improve करने के लिए

3. Public Profile Information

Matrimonial service के लिए कुछ profile information दूसरे users को दिखाई जा सकती है।

Public visibility user की profile settings, photo privacy settings, account status और service functionality पर निर्भर कर सकती है।

Contact details या अन्य sensitive information की visibility membership rules, privacy settings या service controls के अनुसार सीमित की जा सकती है।

4. Profile Photos

User द्वारा upload की गई profile photos matrimonial profile display के लिए उपयोग की जा सकती हैं।

Photo visibility selected privacy setting और platform functionality के अनुसार नियंत्रित की जा सकती है।

5. Identity Documents

Aadhaar, PAN, Voter ID या अन्य identity documents यदि verification purpose के लिए कभी लिए जाते हैं, तो उन्हें सामान्य public matrimonial profile पर display नहीं किया जाना चाहिए।

Users को ऐसे sensitive documents किसी दूसरे user को भेजने से पहले सावधानी बरतनी चाहिए।

6. Firebase और Cloud Services

Indian Vivah Matrimony website और app की technical functionality के लिए third-party cloud services का उपयोग कर सकता है।

Account authentication और profile data storage के लिए Firebase services तथा profile image hosting के लिए cloud image services का उपयोग किया जा सकता है।

इन external services पर data processing उनके applicable technical और privacy controls के अधीन भी हो सकती है।

7. Payment Information

Indian Vivah Matrimony website पर users को card number, CVV, OTP या internet-banking password दर्ज नहीं करना चाहिए।

UPI payment होने पर transaction reference, UTR, payment screenshot या payment confirmation verification के लिए लिया जा सकता है।

8. Information Sharing

Matrimonial profile information service functionality के लिए दूसरे eligible users को दिखाई जा सकती है।

Personal data को अनावश्यक रूप से third parties को बेचने या unrelated commercial use के लिए share करना इस service का उद्देश्य नहीं है।

Legal requirement, fraud investigation, security issue या applicable authority के lawful request की स्थिति में आवश्यक information applicable law के अनुसार disclose की जा सकती है।

9. Account और Profile Updates

Logged-in users अपनी उपलब्ध profile information को Edit Profile feature के माध्यम से update कर सकते हैं।

कुछ information operational या security reason से direct editing के लिए उपलब्ध न भी हो सकती है।

10. Data Security

Indian Vivah Matrimony reasonable technical और operational measures का उपयोग करके user data को unauthorized access, misuse या accidental exposure से protect करने का प्रयास करता है।

हालांकि internet या cloud-based system में absolute security की guarantee नहीं दी जा सकती।

11. User की जिम्मेदारी

  • अपने login credentials सुरक्षित रखें।
  • OTP, password और financial credentials share न करें।
  • Suspicious profile या communication की report करें।
  • Marriage decision से पहले independent verification करें।

12. Profile Removal / Deactivation

User account/profile को hide, deactivate या remove करने के लिए available support channel से request किया जा सकता है।

कुछ records legal, accounting, fraud-prevention, dispute-resolution या technical backup requirements के कारण आवश्यक अवधि तक retain किए जा सकते हैं।

13. Children

Matrimonial service विवाह योग्य adults के लिए है। Minor व्यक्तियों की matrimonial profile registration स्वीकार नहीं की जानी चाहिए।

14. Policy Changes

यह Privacy Policy website/app features, service process या applicable requirements के अनुसार समय-समय पर update की जा सकती है।

15. Contact

Privacy, profile correction, account access या data-related concern के लिए Indian Vivah Matrimony के official support channel से संपर्क करें।

Privacy और safety के लिए किसी matrimonial profile की जानकारी पर केवल निर्भर न रहें। Identity, marital status, employment, family details और अन्य महत्वपूर्ण facts की independent verification करना उचित है।
